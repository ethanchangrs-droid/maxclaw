## 执行过程

### 1. Cargo.toml

添加 `channel-weixin = ["dep:qrcode"]` feature，使 qrcode crate 不仅限于 whatsapp-web feature。

### 2. CLI 登录命令（src/main.rs）

- 添加 `WeixinCommands::Login` 枚举和 `Commands::Weixin` 变体
- 实现 `weixin_login()` 函数：
  - POST get_bot_qrcode 获取 qrcode_url + uuid
  - `#[cfg(feature = "channel-weixin")]` 时用 qrcode crate 终端渲染 Dense1x2
  - 否则降级为打印 URL
  - 长轮询 get_qrcode_status（3 秒间隔，120 秒超时）
  - 支持 status: 0=pending, 1=scanned, 2=confirmed
  - 成功后构造 WeixinConfig 写入 config.channels_config.weixin，调用 config.save()

### 3. Typing 指示器（src/channels/weixin.rs）

- WeixinChannel 新增 `typing_handle: parking_lot::Mutex&lt;Option&lt;JoinHandle&lt;()>>>`
- `start_typing(recipient)`:
  - 先 stop_typing
  - 从 context_tokens 查找对应 token，无则静默跳过
  - spawn 循环：每 4 秒 POST /ilink/bot/sendtyping
  - 存入 typing_handle
- `stop_typing(recipient)`: abort handle

### 4. 游标持久化（src/channels/weixin.rs）

- 新增 `cursor_store_path` 字段，指向 `{workspace}/weixin/weixin_cursor.txt`
- `save_cursor(cursor)`: 异步写磁盘
- `load_cursor()`: 异步读取，NotFound 返回空字符串
- `listen()` 修改：启动时 load_cursor 替代空字符串；cursor 变化时 save_cursor

### 5. 测试

新增 4 个测试：
- `typing_handle_starts_as_none`: 初始状态
- `stop_typing_clears_handle`: abort + 清除
- `cursor_roundtrip`: tempdir 写入读取验证
- `start_typing_skips_without_context_token`: 无 token 时跳过
